
# Calculator Project — Codex Instructions

## Project
This is a simple Python calculator used to learn Git and Codex.

## Coding Rules
- Use Python 3.
- Keep functions simple and readable.
- Add a docstring to every new function.
- Handle invalid inputs when appropriate.

## Testing
- Test every new function.
- Run `python3 calculator.py` after modifying the calculator.

## Git Rules
- Use separate branches for new features.
- Never push to GitHub without permission.
- Never delete branches or worktrees without permission.
- Do not commit changes unless explicitly requested.
